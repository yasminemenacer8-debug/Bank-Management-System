# Bank Management System 💳

A robust and simple command-line **Bank Management System** built with **Python**, designed to manage client accounts, deposits, withdrawals, and secure data persistence using **JSON**.

---

## 🚀 Features
* **Create Account**: Add a new bank account with account number, holder name, and initial balance (with validation checks).
* **Display Accounts**: View all existing accounts and their current balances.
* **Deposit**: Securely add funds to an existing account.
* **Withdraw**: Safely withdraw funds with balance and amount validation checks.
* **Data Persistence**: Automatically saves and loads account data using `accounts.json` so data isn't lost upon exiting.

---

## 🛠️ Built With
* **Language**: Python 3.x
* **Libraries**: `json`, `os`
* **Environment**: macOS / VS Code
